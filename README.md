# Kali Linux Network Investigation

## Project Overview
This beginner-level project documents basic Linux commands and network connectivity testing using Kali Linux running in VirtualBox.

## Objectives
- Learn basic Linux terminal commands.
- Identify network interfaces and IP addresses.
- Understand network routing.
- Test network connectivity.

## Tools Used
- Kali Linux
- Oracle VirtualBox
- Linux Terminal

## Commands Practiced

| Command | Purpose |
|---|---|
| `pwd` | Displays the current working directory |
| `ls` | Lists files and directories |
| `whoami` | Displays the current username |
| `cd` | Changes the current directory |
| `mkdir` | Creates a directory |
| `cat` | Displays file contents |
| `ip a` | Shows network interfaces and IP addresses |
| `ip route` | Displays network routing information |
| `ping -c 4 8.8.8.8` | Tests connectivity to an IP address |
| `ping -c 4 google.com` | Tests connectivity and basic DNS resolution |

## Results
- Practiced basic Linux terminal commands.
- Inspected network interface and routing information.
- Received ping replies from `google.com`, confirming successful connectivity during the test.

## Learning Outcome
Gained beginner-level hands-on experience with Linux commands, IP addressing, routing, and basic network connectivity testing.

## Disclaimer
This project was completed in a personal virtual lab for educational purposes. No unauthorized systems were accessed.
